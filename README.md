# DSAStriver

A C++-based data structures and algorithms practice repository focused on interview preparation, problem-solving, and implementation patterns.

## Overview

This repository contains standalone C++ solutions for common DSA topics, including:

- Arrays and hashing
- Strings and patterns
- Binary search
- Dynamic programming
- Trees and segment trees
- Linked lists
- Intervals and greedy strategies
- Interview-style coding tasks

The code is primarily written for learning and practicing algorithmic thinking in C++ using the standard library.

### Folder breakdown

- Blind75: solutions for the Blind 75 problem set, organized by topic.
- interviewPractice: additional interview-style coding exercises and tasks.
- tree: tree and related data structure implementations.
- smartPointers: a directory for pointer-related practice and experiments.

## Getting started

### Prerequisites

- A C++ compiler such as g++ or clang++
- C++17 or later recommended

### Compile and run a file

From the repository root:

```bash
g++ -std=c++17 Blind75/Array/twoSum1.cpp -o twoSum
./twoSum
```

You can replace the source file with any other implementation in the repository.

## Example topics included

- Two Sum, 3 Sum, and product/sum array problems
- Rotated array search and minimum searches
- Dynamic programming patterns like climbing stairs and coin change
- String problems such as palindrome, anagram, and longest unique substring
- Tree problems such as level-order traversal and max depth
- Linked list tasks like reverse, remove Nth node, and cycle detection
- Segment tree implementations for range queries

## Notes

- Most files are self-contained and include a `main()` function for direct execution.
- This repo is intended for practice, learning, and interview preparation rather than production code.
- The implementations are designed to be simple, readable, and educational.

## Suggested learning path

1. Start with the Array and String folders.
2. Move to Binary Search, DP, and Intervals.
3. Practice Trees and Linked Lists.
4. Use interviewPractice for mixed challenge problems.
5. Revisit solutions and improve time/space complexity where possible.
